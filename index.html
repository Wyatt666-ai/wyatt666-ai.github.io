    项目

    本站的界面与动画实验。

    一页工作台

    用本地指令查找项目和笔记的个人网站，包含一段系统校验风格的启动动画。

    项目详情

    页面和搜索在浏览器内运行，使用 HTML、CSS 和 JavaScript，可部署到 GitHub Pages。

    帝皇铠甲开场实验

    此前的角色变身方案，探索以粒子聚光、分片合体和金光构成网站开场。

    项目详情

    角色插图由 ImageGen 生成。变身原型用 CSS 对同一幅角色图片的不同区域分别做入场动画。

    笔记

    建站过程和可以复用的记录方法。

    把个人网站发布到 GitHub Pages建站

    将站点文件提交到仓库，在 Pages 设置中选择发布分支和根目录。

    首页和 assets 放在同一发布目录里。以后修改内容时，提交到该分支即可触发更新。

    把一次尝试写成一篇短笔记写作

    先写问题，再记录一次尝试和结果，让以后回看时能复现。

    用到的资料、关键步骤和还没想清楚的地方，也可以一起记录。
